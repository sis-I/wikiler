# PROTOTYPE stand-in for AGENTS.md

In a real vault this file is a byte-identical copy of
`src/wikiler/runtime_rules.md`. The prototype leaves it as a pointer so the
contract can be inspected without copying 250 lines.

It is the single source of truth for vault rules: page schema, link grammar,
engine and agent roles, the command reference, and the numbered rules. The four
skills deliberately do not restate any of it.
